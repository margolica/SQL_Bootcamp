# SQL_Bootcamp

## Обзор

Этот репозиторий содержит материалы и задания для SQL Bootcamp, который охватывает различные аспекты работы с реляционными базами данных, включая базовые и продвинутые SQL-запросы, работу с транзакциями, индексами, представлениями, функциями и хранимыми процедурами. Каждый день обучения посвящен определенной теме, которая помогает участникам углубить свои знания и навыки в SQL.
## Содержание
### День 00: Введение в реляционную модель данных и SQL
**Основные концепции:** Реляционная модель данных, базовые SQL-запросы.

**Задания:**

- Получение данных о людях из определенного города.

- Сортировка данных по возрасту и имени.

- Использование операторов BETWEEN и сравнения для фильтрации данных.

### День 01: Работа с множествами и JOIN

**Основные концепции:** Операции с множествами, JOIN-запросы.

**Задания:**

- Объединение данных из разных таблиц с использованием UNION.

- Поиск дубликатов и уникальных значений.

- Использование JOIN для объединения данных.

### День 02: Продвинутые JOIN и изменение данных

**Основные концепции:** Различные типы JOIN, изменение данных с помощью DML.

**Задания:**

- Использование LEFT, RIGHT, FULL JOIN.

- Решение задач на обновление и удаление данных.

### День 03: Транзакции и уровни изоляции

**Основные концепции:** Транзакции, уровни изоляции, аномалии данных.

**Задания:**

- Воспроизведение аномалий "Потерянное обновление", "Неповторяемое чтение", "Фантомное чтение".

- Работа с уровнями изоляции READ COMMITTED, REPEATABLE READ, SERIALIZABLE.

### День 04: Виртуальные таблицы и материализованные представления

**Основные концепции:** Виртуальные таблицы, материализованные представления.

**Задания:**

- Создание и использование представлений.

- Работа с материализованными представлениями.

### День 05: Индексы и производительность

**Основные концепции:** Индексы, оптимизация запросов.

**Задания:**

- Создание индексов для улучшения производительности запросов.

- Анализ выполнения запросов с помощью EXPLAIN ANALYZE.

### День 06: Расширение модели данных и скидки

**Основные концепции:** Расширение модели данных, работа с персональными скидками.

**Задания:**

- Создание таблицы для хранения скидок.

- Расчет скидок на основе истории заказов.

### День 07: Агрегация данных и OLAP

**Основные концепции:** Агрегация данных, OLAP-запросы.

**Задания:**

- Агрегация данных по пользователям и типам баланса.

- Расчет объема транзакций в USD.

### День 08: Транзакции и взаимоблокировки

**Основные концепции:** Транзакции, взаимоблокировки.

**Задания:**

- Воспроизведение ситуации взаимоблокировки.

- Работа с транзакциями для предотвращения аномалий.

### День 09: Функции и триггеры

**Основные концепции:** Функции, триггеры, аудит изменений.

**Задания:**

- Создание функций для обработки данных.

- Реализация аудита изменений с помощью триггеров.

### Командные задания 00:

**Задача коммивояжёра (TSP):** Решение задачи коммивояжёра с использованием SQL.

### Командные задания 01:

**Хранилище данных (DWH):** Создание ETL-процесса для обработки данных из различных источников.
