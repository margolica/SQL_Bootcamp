# SQL_bootcamp_day_00

## Реляционная модель данных и SQL

Знакомство с реляционной моделью данных и запрос данных на основе базовых конструкций SQL.

## Задачи

### Упражнение 00

Необходимо получить имена и возраст всех людей проживающих в Казани.

### Упражнение 01

Необходимо получить имена и возраст всех женщин из города Казань, отсортированных по имени.

### Упражнение 02

Необходимо составить два оператора выбора, возвращающих список пиццерий с рейтингом от 3,5 до 5 баллов (включая
предельные баллы), упорядоченных по рейтингу пиццерии.

### Упражнение 03

Необходимо получить идентификаторы человека, который посетил пиццерии в период с 06.01.2022 по 09.01.2022  (включая
предельные даты) или посетил пиццерию с идентификатором "2". Отсортировать результат по идентификатору человека в
нисходящий режим.

### Упражнение 04

Необходимо составить оператор выбора, который возвращает одно вычисляемое поле с именем «person_information» в одной
строке. Отсортировать по вычисляемому столбцу в порядке возрастания.

### Упражнение 05

Необходимо составить оператор выбора, который возвращает имена людей на основе внутреннего запроса в `SELECT`, которые
сделали заказы на меню с идентификаторами "13", "14" и "18", а дата заказа должна быть равна 07.01.2022.

### Упражнение 06

На основе конструкции SQL из упражнения 05, необходимо добавить новый вычисляемый столбец «check_name» с оператором
проверки.
Псевдокод код оператора проверки:

``` SQL
if (person_name == 'Denis') then return true
    else return false
```

### Упражнение 07

Необходимо составить оператор SQL, который возвращает идентификаторы человека, имена человека и интервал возраста
человека и отсортировать результат по столбцу «interval_info» в порядке возрастания.
Интервалы данных для `person`:

```SQL
if
(age >= 10 and age <= 20) then return 'interval #1'
else if (age > 20 and age < 24) then return 'interval #2'
else return 'interval #3'
```

### Упражнение 08

Необходимо составить оператор который возвращает все столбцы из таблицы `person_order`  со строками, идентификатор
которых является четным числом. Результат необходимо упорядочить по возвращаемому идентификатору.

### Упражнение 09

Необходимо составить оператор, который возвращает имена людей и названия пиццерий на основе таблицы `person_visits`  с
датой посещения в период с 06.01.2022 по 09.01.2022  (включая предельные даты)  с внутренним запросом в `FROM`
.Результат необходимо упорядочить по имени человека в порядке возрастания и по названию пиццерии в порядке убывания.
