# SQL_bootcamp_day_01

## Первые шаги в работе с множествами и JOIN в SQL

Знакомство с множествами и простыми JOIN в SQL для получения необходимых данных.

## Задачи

### Упражнение 00

Необходимо написать SQL-запрос, который возвращает идентификатор меню и названия пицц из таблицы `menu`, а также идентификатор и имя человека из таблицы `person` в одном общем списке. Результат должен быть отсортирован по `object_id`, а затем по `object_name`.

### Упражнение 01

Необходимо модифицировать SQL-запрос из упражнения 00, удалив столбец `object_id`. Затем изменить порядок сортировки по `object_name` для данных из таблицы `person`, а затем из таблицы `menu`. Сохранить дубликаты.

### Упражнение 02

Необходимо написать SQL-запрос, который возвращает уникальные названия пицц из таблицы `menu`, отсортированные по столбцу `pizza_name` в порядке убывания. Обратите внимание на раздел "Запрещено".

### Упражнение 03

Необходимо написать SQL-запрос, который возвращает общие строки для атрибутов `order_date` и `person_id` из таблицы `person_order` и `visit_date` и `person_id` из таблицы `person_visits`. Другими словами, найти идентификаторы людей, которые посетили пиццерию и заказали пиццу в один и тот же день. Отсортировать результат по `action_date` в порядке возрастания, а затем по `person_id` в порядке убывания.

### Упражнение 04

Необходимо написать SQL-запрос, который возвращает разницу (минус) значений столбца `person_id` с сохранением дубликатов между таблицами `person_order` и `person_visits` для дат заказа и посещения 7 января 2022 года.

### Упражнение 05

Необходимо написать SQL-запрос, который возвращает все возможные комбинации между таблицами `person` и `pizzeria`. Отсортировать результат по идентификатору человека, а затем по идентификатору пиццерии.

### Упражнение 06

Необходимо вернуться к упражнению 03 и изменить SQL-запрос так, чтобы он возвращал имена людей вместо их идентификаторов. Отсортировать результат по `action_date` в порядке возрастания, а затем по `person_name` в порядке убывания.

### Упражнение 07

Необходимо написать SQL-запрос, который возвращает дату заказа из таблицы `person_order` и соответствующее имя человека из таблицы `person`. Отсортировать результат по обоим столбцам в порядке возрастания.

### Упражнение 08

Необходимо переписать SQL-запрос из упражнения 07, используя конструкцию `NATURAL JOIN`. Результат должен быть таким же, как в упражнении 07.

### Упражнение 09

Необходимо написать два SQL-запроса, которые возвращают список названий пиццерий, которые не были посещены людьми. Первый запрос должен использовать `IN`, а второй — `EXISTS`.

### Упражнение 10

Необходимо написать SQL-запрос, который возвращает список имен людей, которые сделали заказ на пиццу в соответствующей пиццерии. Отсортировать результат по трем столбцам (`person_name`, `pizza_name`, `pizzeria_name`) в порядке возрастания.
