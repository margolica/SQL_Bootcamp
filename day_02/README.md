# SQL_bootcamp_day_02

## Погружение в JOIN в SQL

Знакомство с различными типами JOIN для получения необходимых данных.

## Задачи

### Упражнение 00

Необходимо написать SQL-запрос, который возвращает список названий пиццерий и их рейтингов, которые не были посещены людьми.

### Упражнение 01

Необходимо написать SQL-запрос, который возвращает пропущенные дни с 1 по 10 января 2022 года (включая все дни) для посещений людей с идентификаторами 1 или 2. Отсортировать результат по датам посещения в порядке возрастания.

### Упражнение 02

Необходимо написать SQL-запрос, который возвращает полный список имен людей, которые посещали (или не посещали) пиццерии в период с 1 по 3 января 2022 года, и полный список названий пиццерий, которые были посещены (или не посещены). Заменить значения `NULL` на `-` в столбцах `person_name` и `pizzeria_name`. Отсортировать результат по всем трем столбцам.

### Упражнение 03

Необходимо переписать SQL-запрос из упражнения 01, используя CTE (Common Table Expression). Результат должен быть аналогичным.

### Упражнение 04

Необходимо найти полную информацию о всех возможных названиях пиццерий и ценах на пиццы с грибами или пепперони. Отсортировать результат по названию пиццы и названию пиццерии.

### Упражнение 05

Необходимо найти имена всех женщин старше 25 лет и отсортировать результат по имени.

### Упражнение 06

Необходимо найти все названия пицц (и соответствующие названия пиццерий из таблицы `menu`), которые заказали Денис или Анна. Отсортировать результат по обоим столбцам.

### Упражнение 07

Необходимо найти название пиццерии, которую Дмитрий посетил 8 января 2022 года и где он мог съесть пиццу дешевле 800 рублей.

### Упражнение 08

Необходимо найти имена всех мужчин из Москвы или Самары, которые заказывали пиццы с пепперони или грибами (или обе). Отсортировать результат по имени человека в порядке убывания.

### Упражнение 09

Необходимо найти имена всех женщин, которые заказывали как пиццы с пепперони, так и с сыром (в любое время и в любых пиццериях). Отсортировать результат по имени человека.

### Упражнение 10

Необходимо найти имена людей, которые живут по одному адресу. Отсортировать результат по имени первого человека, имени второго человека и общему адресу.
