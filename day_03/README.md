# SQL_bootcamp_day_03

## Продолжение работы с JOIN и изменение данных

Знакомство с изменением данных с использованием языка DML.

## Задачи

### Упражнение 00

Необходимо написать SQL-запрос, который возвращает список названий пицц, их цен, названий пиццерий и дат посещения для Кейт, где цена находится в диапазоне от 800 до 1000 рублей. Отсортировать результат по названию пиццы, цене и названию пиццерии.

### Упражнение 01

Необходимо найти все идентификаторы меню, которые не были заказаны ни одним человеком. Результат должен быть отсортирован по идентификаторам.

### Упражнение 02

Необходимо использовать SQL-запрос из упражнения 01 и показать названия пицц из пиццерий, которые не были заказаны ни одним человеком, включая соответствующие цены. Результат должен быть отсортирован по названию пиццы и цене.

### Упражнение 03

Необходимо найти пиццерии, которые чаще посещались женщинами или мужчинами. Сохранить дубликаты при использовании операторов с множествами (UNION ALL, EXCEPT ALL, INTERSECT ALL). Отсортировать результат по названию пиццерии.

### Упражнение 04

Необходимо найти объединение пиццерий, которые были заказаны только женщинами или только мужчинами. Не сохранять дубликаты при использовании операторов с множествами (UNION, EXCEPT, INTERSECT). Отсортировать результат по названию пиццерии.

### Упражнение 05

Необходимо написать SQL-запрос, который возвращает список пиццерий, которые Андрей посетил, но не сделал ни одного заказа. Отсортировать результат по названию пиццерии.

### Упражнение 06

Необходимо найти одинаковые названия пицц, которые имеют одинаковую цену, но из разных пиццерий. Отсортировать результат по названию пиццы.

### Упражнение 07

Необходимо зарегистрировать новую пиццу с названием «greek pizza» (id = 19) с ценой 800 рублей в ресторане «Dominos» (pizzeria_id = 2).

### Упражнение 08

Необходимо зарегистрировать новую пиццу с названием «sicilian pizza» (id должен быть рассчитан по формуле «максимальное значение id + 1») с ценой 900 рублей в ресторане «Dominos» (используйте внутренний запрос для получения идентификатора пиццерии).

### Упражнение 09

Необходимо зарегистрировать новые посещения ресторана «Dominos» от Дениса и Ирины 24 февраля 2022 года.

### Упражнение 10

Необходимо зарегистрировать новые заказы от Дениса и Ирины 24 февраля 2022 года для нового меню с «sicilian pizza».

### Упражнение 11

Необходимо изменить цену на «greek pizza» на -10% от текущего значения.

### Упражнение 12

Необходимо зарегистрировать новые заказы от всех людей на «greek pizza» 25 февраля 2022 года.

### Упражнение 13

Необходимо написать 2 SQL (DML) запроса, которые удаляют все новые заказы из упражнения 12 на основе даты заказа. Затем удалить «greek pizza» из меню.
