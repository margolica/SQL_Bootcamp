# SQL_bootcamp_day_04

## Снимки данных, виртуальные таблицы

Знакомство с использованием виртуальных представлений и физических снимков данных.

## Задачи

### Упражнение 00

Необходимо создать 2 представления базы данных (`v_persons_female` и `v_persons_male`) на основе фильтрации по полу людей. Представления должны содержать аналогичные атрибуты, как и исходная таблица.

### Упражнение 01

Необходимо использовать 2 представления из упражнения 00 и написать SQL-запрос, который возвращает имена женщин и мужчин в одном списке. Отсортировать результат по имени человека.

### Упражнение 02

Необходимо создать представление базы данных `v_generated_dates`, которое будет "хранить" сгенерированные даты с 1 по 31 января 2022 года в типе DATE. Убедитесь, что столбец `generated_date` отсортирован.

### Упражнение 03

Необходимо написать SQL-запрос, который возвращает пропущенные дни для посещений людей в январе 2022 года. Используйте представление `v_generated_dates` для этой задачи и отсортируйте результат по столбцу `missing_date`.

### Упражнение 04

Необходимо написать SQL-запрос, который удовлетворяет формуле `(R - S)∪(S - R)`, где R — таблица `person_visits` с фильтром по 2 января 2022 года, а S — таблица `person_visits` с фильтром по 6 января 2022 года. Результат должен содержать только столбец `person_id`, отсортированный по этому столбцу. Представьте итоговый SQL в виде представления базы данных `v_symmetric_union`.

### Упражнение 05

Необходимо создать представление базы данных `v_price_with_discount`, которое возвращает заказы людей с именами, названиями пицц, реальной ценой и рассчитанной колонкой `discount_price` (с применением скидки 10% и формулой `price - price*0.1`). Отсортировать результат по имени человека и названию пиццы, округлить `discount_price` до целого числа.

### Упражнение 06

Необходимо создать материализованное представление `mv_dmitriy_visits_and_eats` (с включенными данными) на основе SQL-запроса, который находит название пиццерии, которую Дмитрий посетил 8 января 2022 года и где он мог съесть пиццу дешевле 800 рублей.

### Упражнение 07

Необходимо обновить данные в материализованном представлении `mv_dmitriy_visits_and_eats` из упражнения 06. Перед этим действием добавьте новое посещение Дмитрия, которое удовлетворяет условию SQL-запроса материализованного представления, кроме пиццерии, которая уже есть в результате из упражнения 06. После добавления нового посещения обновите состояние данных в `mv_dmitriy_visits_and_eats`.

### Упражнение 08

После выполнения всех упражнений у нас появилось несколько виртуальных таблиц и одно материализованное представление. Необходимо удалить их!
