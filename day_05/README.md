# SQL_bootcamp_day_05

## Я улучшил свой SQL-запрос! Пожалуйста, предоставьте доказательства!

Знакомство с созданием индексов в базе данных и их влиянием на производительность запросов.

## Задачи

### Упражнение 00

Необходимо создать простой BTree-индекс для каждого внешнего ключа в нашей базе данных. Имя индекса должно соответствовать шаблону `idx_{table_name}_{column_name}`. Например, имя индекса для столбца `pizzeria_id` в таблице `menu` будет `idx_menu_pizzeria_id`.

### Упражнение 01

Необходимо написать SQL-запрос, который возвращает названия пицц и соответствующие названия пиццерий. Затем предоставить доказательство того, что индексы работают, используя команду `EXPLAIN ANALYZE`.

### Упражнение 02

Необходимо создать функциональный BTree-индекс с именем `idx_person_name` для столбца `name` в таблице `person`. Индекс должен содержать имена людей в верхнем регистре. Предоставить SQL-запрос с доказательством (`EXPLAIN ANALYZE`), что индекс работает.

### Упражнение 03

Необходимо создать многоколоночный BTree-индекс с именем `idx_person_order_multi` для SQL-запроса, который выбирает `person_id`, `menu_id` и `order_date` из таблицы `person_order` с условием `person_id = 8 AND menu_id = 19`. Предоставить доказательство (`EXPLAIN ANALYZE`), что индекс работает.

### Упражнение 04

Необходимо создать уникальный BTree-индекс с именем `idx_menu_unique` на таблице `menu` для столбцов `pizzeria_id` и `pizza_name`. Предоставить SQL-запрос с доказательством (`EXPLAIN ANALYZE`), что индекс работает.

### Упражнение 05

Необходимо создать частичный уникальный BTree-индекс с именем `idx_person_order_order_date` на таблице `person_order` для столбцов `person_id` и `menu_id` с частичной уникальностью для столбца `order_date` на дату ‘2022-01-01’. Предоставить доказательство (`EXPLAIN ANALYZE`), что индекс работает.

### Упражнение 06

Необходимо создать новый BTree-индекс с именем `idx_1`, который улучшит метрику “Execution Time” для SQL-запроса, использующего оконную функцию. Предоставить доказательство (`EXPLAIN ANALYZE`), что SQL-запрос был улучшен.
