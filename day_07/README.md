# SQL_bootcamp_day_07

## Агрегированные данные более информативны, не так ли?

Знакомство с использованием OLAP-конструкций для получения "ценности" из данных.

## Задачи

### Упражнение 00

Необходимо написать SQL-запрос, который возвращает идентификаторы людей и соответствующее количество посещений любых пиццерий. Результат должен быть отсортирован по количеству посещений в порядке убывания и по `person_id` в порядке возрастания.

### Упражнение 01

Необходимо изменить SQL-запрос из упражнения 00, чтобы возвращать имена людей (а не идентификаторы). Дополнительное условие: нужно показать только топ-4 людей с максимальным количеством посещений любых пиццерий. Результат должен быть отсортирован по имени человека.

### Упражнение 02

Необходимо написать SQL-запрос, который показывает 3 любимых ресторана по посещениям и заказам в одном списке. Добавьте столбец `action_type` со значениями `order` или `visit` в зависимости от данных. Результат должен быть отсортирован по `action_type` в порядке возрастания и по количеству в порядке убывания.

### Упражнение 03

Необходимо написать SQL-запрос, который группирует рестораны по посещениям и заказам, а затем объединяет их по названию ресторана. Дополнительно:
- Рассчитайте сумму заказов и посещений для каждой пиццерии.
- Отсортируйте результат по `total_count` в порядке убывания и по `name` в порядке возрастания.

### Упражнение 04

Необходимо написать SQL-запрос, который возвращает имя человека и количество посещений любых пиццерий, если человек посетил пиццерии более 3 раз (> 3).

### Упражнение 05

Необходимо написать простой SQL-запрос, который возвращает список уникальных имен людей, сделавших заказы в любых пиццериях. Результат должен быть отсортирован по имени человека.

### Упражнение 06

Необходимо написать SQL-запрос, который возвращает количество заказов, среднюю цену, максимальную и минимальную цены для проданных пицц в соответствующей пиццерии. Результат должен быть отсортирован по названию пиццерии. Среднюю цену округлите до 2 знаков после запятой.

### Упражнение 07

Необходимо написать SQL-запрос, который возвращает общий средний рейтинг (название выходного атрибута — `global_rating`) для всех ресторанов. Округлите средний рейтинг до 4 знаков после запятой.

### Упражнение 08

Необходимо написать SQL-запрос, который возвращает адрес, название пиццерии и количество заказов людей. Результат должен быть отсортирован по адресу, а затем по названию ресторана.

### Упражнение 09

Необходимо написать SQL-запрос, который возвращает агрегированную информацию по адресу человека. Результат должен включать:
- Формулу "Максимальный возраст - (Минимальный возраст / Максимальный возраст)".
- Средний возраст по адресу.
- Сравнение между формулой и средним возрастом (если формула больше среднего, то `True`, иначе `False`).

Результат должен быть отсортирован по адресу.
