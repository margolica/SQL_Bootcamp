# SQL_bootcamp_day_08

## Изоляция — одно из свойств ACID

Знакомство с работой базы данных с транзакциями и уровнями изоляции.

## Задачи

### Упражнение 00

Необходимо использовать командную строку PostgreSQL (psql) для проверки, как изменения публикуются в базе данных для других пользователей. Вам нужно два активных сеанса (параллельные сеансы в командной строке). Покажите, что параллельный сеанс не видит ваши изменения до тех пор, пока вы не выполните `COMMIT`.

### Упражнение 01

Необходимо воспроизвести аномалию "Потерянное обновление" (Lost Update Anomaly) на уровне изоляции "read committed". Проверьте рейтинг для “Pizza Hut” в режиме транзакции для обеих сессий, затем обновите рейтинг до 4 в сессии #1 и до 3.6 в сессии #2.

### Упражнение 02

Необходимо воспроизвести аномалию "Потерянное обновление" (Lost Update Anomaly) на уровне изоляции "repeatable read". Проверьте рейтинг для “Pizza Hut” в режиме транзакции для обеих сессий, затем обновите рейтинг до 4 в сессии #1 и до 3.6 в сессии #2.

### Упражнение 03

Необходимо воспроизвести аномалию "Неповторяемое чтение" (Non-Repeatable Reads Anomaly) на уровне изоляции "read committed". Проверьте рейтинг для “Pizza Hut” в режиме транзакции для сессии #1, затем обновите рейтинг до 3.6 в сессии #2.

### Упражнение 04

Необходимо воспроизвести аномалию "Неповторяемое чтение" (Non-Repeatable Reads Anomaly) на уровне изоляции "serializable". Проверьте рейтинг для “Pizza Hut” в режиме транзакции для сессии #1, затем обновите рейтинг до 3.0 в сессии #2.

### Упражнение 05

Необходимо воспроизвести аномалию "Фантомное чтение" (Phantom Reads Anomaly) на уровне изоляции "read committed". Проверьте сумму всех рейтингов для всех пиццерий в режиме транзакции для сессии #1, затем обновите рейтинг для “Pizza Hut” до 1 в сессии #2.

### Упражнение 06

Необходимо воспроизвести аномалию "Фантомное чтение" (Phantom Reads Anomaly) на уровне изоляции "repeatable read". Проверьте сумму всех рейтингов для всех пиццерий в режиме транзакции для сессии #1, затем обновите рейтинг для “Pizza Hut” до 5 в сессии #2.

### Упражнение 07

Необходимо воспроизвести ситуацию "Взаимоблокировка" (Deadlock) в базе данных. Напишите любой SQL-запрос на таблицу `pizzeria` с любым уровнем изоляции, чтобы воспроизвести эту ситуацию.
