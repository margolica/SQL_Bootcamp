# SQL_bootcamp_day_09

## RDBMS — это не только таблицы

Знакомство с созданием и использованием функциональных блоков в базах данных.

## Задачи

### Упражнение 00

Необходимо создать таблицу `person_audit` с той же структурой, что и таблица `person`, но с дополнительными столбцами:
- `created` — временная метка создания события (по умолчанию текущее время).
- `type_event` — тип события (I — вставка, U — обновление, D — удаление).
- `row_id` — копия `person.id`.

Создайте триггерную функцию `fnc_trg_person_insert_audit`, которая будет обрабатывать вставку данных в таблицу `person` и копировать новую строку в таблицу `person_audit`. Затем создайте триггер `trg_person_insert_audit`, который будет вызывать эту функцию после вставки.

### Упражнение 01

Необходимо создать триггер `trg_person_update_audit` и соответствующую функцию `fnc_trg_person_update_audit`, чтобы обрабатывать обновления в таблице `person` и сохранять старые значения атрибутов в таблице `person_audit`.

### Упражнение 02

Необходимо создать триггер `trg_person_delete_audit` и соответствующую функцию `fnc_trg_person_delete_audit`, чтобы обрабатывать удаления в таблице `person` и сохранять старые значения атрибутов в таблице `person_audit`.

### Упражнение 03

Необходимо объединить логику всех триггеров в один главный триггер `trg_person_audit` и соответствующую функцию `fnc_trg_person_audit`. Удалите старые триггеры и функции, а затем очистите таблицу `person_audit`. После этого повторно примените набор DML-операций.

### Упражнение 04

Необходимо создать две SQL-функции:
- `fnc_persons_female` — возвращает женщин.
- `fnc_persons_male` — возвращает мужчин.

### Упражнение 05

Необходимо создать общую SQL-функцию `fnc_persons` с параметром `pgender` (по умолчанию 'female'), которая будет возвращать людей в зависимости от пола.

### Упражнение 06

Необходимо создать PL/pgSQL-функцию `fnc_person_visits_and_eats_on_date`, которая возвращает названия пиццерий, которые посетил человек (параметр `pperson`) и где он мог купить пиццу дешевле заданной суммы (параметр `pprice`) на определенную дату (параметр `pdate`).

### Упражнение 07

Необходимо написать SQL или PL/pgSQL-функцию `func_minimum`, которая принимает массив чисел и возвращает минимальное значение.

### Упражнение 08

Необходимо написать SQL или PL/pgSQL-функцию `fnc_fibonacci`, которая принимает параметр `pstop` (по умолчанию 10) и возвращает таблицу с числами Фибоначчи, меньшими чем `pstop`.
