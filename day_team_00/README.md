# Team 00 - Piscine SQL

## Задача коммивояжёра (TSP)

Сегодня вы реализуете быстрое решение на SQL для достижения результатов задачи коммивояжёра.

## Задачи

### Упражнение 00

Необходимо создать таблицу `nodes` со структурой `{point1, point2, cost}` и заполнить её данными на основе графа, представленного на изображении. Учтите, что между двумя узлами есть как прямые, так и обратные пути.

Напишите SQL-запрос, который возвращает все туры (пути) с минимальной стоимостью, если начинать с города "a". Тур должен включать посещение всех городов и возврат в начальную точку. Например, тур может выглядеть так: `a -> b -> c -> d -> a`.

Пример выходных данных:

| total_cost | tour |
| ------ | ------ |
| 80 | {a,b,d,c,a} |
| ... | ... |

### Упражнение 01

Добавьте возможность видеть дополнительные строки с самой высокой стоимостью к SQL-запросу из предыдущего упражнения. Пример выходных данных:

| total_cost | tour |
| ------ | ------ |
| 80 | {a,b,d,c,a} |
| ... | ... |
| 95 | {a,d,c,b,a} |
