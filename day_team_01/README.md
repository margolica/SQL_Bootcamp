# Team 01 - Piscine SQL

## Хранилище данных (DWH)

Сегодня вы узнаете, что такое DWH и как создать первый ETL-процесс.

## Задачи

### Упражнение 00

Необходимо написать SQL-запрос, который возвращает общий объем транзакций (сумму всех денег) из баланса пользователя, агрегированный по пользователю и типу баланса. Учтите, что все данные должны быть обработаны, включая данные с аномалиями.

Пример выходных данных:

| name   | lastname | type | volume | currency_name | last_rate_to_usd | total_volume_in_usd |
|--------| ------ |------| ------ | ------ | ------ | ------ |
| Петр   | not defined | 2    | 203 | not defined | 1 | 203 |
| Иван   | Иванов | 1    | 410 | EUR | 0.9 | 369 |

### Упражнение 01

Перед выполнением задачи примените следующие INSERT-запросы:

```sql
insert into currency values (100, 'EUR', 0.85, '2022-01-01 13:29');
insert into currency values (100, 'EUR', 0.79, '2022-01-08 13:29');
```

Необходимо написать SQL-запрос, который возвращает всех пользователей, все транзакции баланса (игнорируя валюты, которые не имеют ключа в таблице Currency) с названием валюты и рассчитанным значением валюты в USD для ближайшего дня.

Пример выходных данных:

| name| lastname   | currency_name | currency_in_usd |
|------|-----------|------------------|---------------|
| Иван | Иванов    | EUR              | 150.1         |
| Иван | Иванов    | EUR              | 17            |
